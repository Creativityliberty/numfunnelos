Architecture Fonctionnelle

Nüptin Funnel OS est organisé autour de trois concepts fondamentaux :

ConceptRôle
WorkspaceEspace de travail isolé par entreprise ou créateur. Toutes les ressources portent un workspace_id.
FunnelTunnel de conversion sous forme de brouillon JSON éditable et versionnable.
FunnelVersionSnapshot immuable créé à chaque publication. Active l'URL publique /f/{slug}.

Authentification & Tokens

Les jetons MCP permettent à votre agent IA de piloter le studio Nüptin avec des permissions précises et révocables à tout moment.

Format du Token

Header HTTP
Authorization: Bearer num_mcp_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

Scopes Disponibles

ScopeAccèsUsage
funnels:readLectureLister et consulter les tunnels existants.
funnels:writeLecture + ÉcritureCréer et modifier des brouillons de tunnels.
funnels:publishRead + Write + PublishMettre en ligne officiellement un tunnel en production.
⚠ Le token est affiché une seule fois à la création. Conservez-le immédiatement dans votre coffre de secrets.

Générer un Token via API

cURL
curl -X POST https://nuptin.coolify.dallico.com/api/mcp/tokens \
  -H "Content-Type: application/json" \
  -H "Cookie: session=..." \
  -d '{"label":"Mon Agent","scopes":["funnels:read","funnels:write","funnels:publish"],"valid_days":30}'
Guide

Premier tunnel en 5 minutes

Créez, personnalisez et publiez votre premier tunnel avec votre agent IA en 4 étapes simples.

Étape 1 — Générer votre token

Studio Nüptin → Espaces de travail → Connecter mon Agent IA → Copiez votre jeton MCP.

Étape 2 — Configurer votre agent

Variables d'environnement
NUM_MCP_API_URL=https://nuptin.coolify.dallico.com
NUM_MCP_TOKEN=num_mcp_votre_token_ici

Étape 3 — Créer le tunnel

Agent IA
create_optin(name="Coaching Business Elite", template="app7")
cURL
curl -X POST https://nuptin.coolify.dallico.com/api/agent/funnels \
  -H "Authorization: Bearer num_mcp_..." \
  -H "Content-Type: application/json" \
  -d '{"name":"Coaching Business Elite","template":"app7"}'
Python
import httpx
r = httpx.post(
    "https://nuptin.coolify.dallico.com/api/agent/funnels",
    headers={"Authorization": "Bearer num_mcp_..."},
    json={"name": "Coaching Business Elite", "template": "app7"}
)
funnel_id = r.json()["id"]

Étape 4 — Publier

MCP Tool
publish_funnel(funnel_id="9b156448-...")
# → {"url": "/f/coaching-business-elite-a1b2", "version": 1}
✓ Votre tunnel est en ligne. Les prospects apparaissent automatiquement dans votre CRM Nüptin en temps réel.

MCP Tool

create_optin(name, template)

Initialise un tunnel à partir d'un modèle prédéfini, sans le publier. Retourne le brouillon JSON éditable.

ParamètreTypeDescription
namerequisstringNom du tunnel (2 à 150 caractères).
templateoptionnel"app7" | "ebook1"app7 : High-Ticket 4 étapes (défaut). ebook1 : Ebook 2 étapes.
MCP Tool
# Modèle High-Ticket
create_optin(name="Coaching Business Elite", template="app7")

# Modèle Ebook
create_optin(name="Les 7 Leviers du Marketing Autonome", template="ebook1")

Templates

TemplateStructureUsage idéal
app74 étapes : Capture → VSL → Candidature → Cal.comCoaching, formations premium, offres high-ticket.
ebook12 étapes : Capture + Chapitre → Auteur + Amazon + WhatsAppEbooks, lead magnets, vente Amazon.

MCP Tool

update_funnel_draft(funnel_id, draft)

Remplacement complet du document JSON du tunnel — étapes, formulaires, intégrations, mentions légales.

⚠Ce tool remplace l'intégralité du draft. Lisez toujours d'abord avec get_funnel(), modifiez les champs nécessaires, puis renvoyez l'objet complet. Limite : 120 000 caractères JSON.
ParamètreTypeDescription
funnel_idrequisstring (UUID)Identifiant du tunnel.
draftrequisobjectDocument JSON complet. Doit contenir les clés copy et brand.
Flux recommandé
# 1. Lire le brouillon existant
tunnel = get_funnel(funnel_id="9b156448-...")
draft = tunnel["draft"]

# 2. Modifier les champs nécessaires
draft["copy"]["title"] = "Mon nouveau titre"
draft["steps"][0]["badge"] = "ACCÈS IMMÉDIAT"

# 3. Mettre à jour
update_funnel_draft(funnel_id="9b156448-...", draft=draft)
