Architecture Fonctionnelle

Nüptin Funnel OS est organisé autour de trois concepts fondamentaux :

ConceptRôle
WorkspaceEspace de travail isolé par entreprise ou créateur. Toutes les ressources sont scoped par workspace_id.
FunnelTunnel de conversion en brouillon éditable. Structure JSON versionnable.
FunnelVersionSnapshot immuable créé à chaque publication. URL publique active.

Authentification & Tokens

Les jetons d'accès MCP permettent à votre agent IA de piloter votre studio Nüptin avec des permissions précises et révocables.

Format du Token

Tout token agent Nüptin commence par num_mcp_ suivi de 64 caractères hexadécimaux.

Header HTTP 
Authorization: Bearer num_mcp_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

Scopes Disponibles

ScopeAccèsUsage
funnels:read Lecture seule Lister et consulter les tunnels existants.
funnels:write Lecture + Écriture Créer et modifier des brouillons de tunnels.
funnels:publish Lecture + Écriture + Publication Mettre en ligne officiellement un tunnel en production.
⚠ Le token est affiché une seule fois à la création. Conservez-le immédiatement dans votre coffre de secrets. En cas de perte, révoquez-le et générez-en un nouveau.

Générer un Token (depuis le Studio)

Dans le Studio Nüptin : Espaces de travail → Connecter mon Agent IA → Générer un jeton.

Ou via l'API REST directement :

cURL 
curl -X POST https://nuptin.coolify.dallico.com/api/mcp/tokens \
  -H "Content-Type: application/json" \
  -H "Cookie: session=..." \
  -d '{"label":"Mon Agent IA","scopes":["funnels:read","funnels:write","funnels:publish"],"valid_days":30}'
Guide

Premier tunnel en 5 minutes

Créez, personnalisez et publiez votre premier tunnel de conversion avec votre agent IA en 4 étapes simples.

Étape 1 — Générer votre token

Depuis le Studio Nüptin, naviguez vers Espaces de travail → Connecter mon Agent IA et copiez votre jeton MCP.

Étape 2 — Configurer votre agent

Ajoutez les deux variables d'environnement à votre agent :

Variables d'environnement
NUM_MCP_API_URL=https://nuptin.coolify.dallico.com
NUM_MCP_TOKEN=num_mcp_votre_token_ici

Étape 3 — Créer votre tunnel

Agent IA
# Demandez à votre agent IA :
"Crée un tunnel Nüptin nommé 'Coaching Business Elite'
 avec le modèle High-Ticket APP 7"

# L'agent appelle automatiquement :
create_optin(name="Coaching Business Elite", template="app7")
cURL
curl -X POST https://nuptin.coolify.dallico.com/api/agent/funnels \
  -H "Authorization: Bearer num_mcp_..." \
  -H "Content-Type: application/json" \
  -d '{"name":"Coaching Business Elite","template":"app7"}'
Python
import httpx

r = httpx.post(
    "https://nuptin.coolify.dallico.com/api/agent/funnels",
    headers={"Authorization": "Bearer num_mcp_..."},
    json={"name": "Coaching Business Elite", "template": "app7"}
)
funnel = r.json()
print(funnel["id"])  # → "9b156448-..."

Étape 4 — Publier

MCP Tool
publish_funnel(funnel_id="9b156448-...")
# → {"url": "/f/coaching-business-elite-a1b2c3d4", "version": 1}
✓ Votre tunnel est en ligne ! Partagez l'URL publique à vos prospects et suivez leurs candidatures dans le CRM Nüptin.

Configuration MCP

Déclarez Nüptin comme serveur MCP dans Cursor, Claude Desktop ou Antigravity en quelques lignes.

Claude Desktop / Antigravity

Ajoutez le bloc suivant dans votre fichier mcp_config.json (ou claude_desktop_config.json) :

JSON
{
  "mcpServers": {
    "nuptin": {
      "command": "python3",
      "args": ["-m", "server.mcp_server"],
      "env": {
        "NUM_MCP_API_URL": "https://nuptin.coolify.dallico.com",
        "NUM_MCP_TOKEN": "num_mcp_VOTRE_TOKEN_ICI"
      }
    }
  }
}

Cursor / Windsurf

Dans .cursor/mcp.json à la racine du projet :

JSON
{
  "mcpServers": {
    "nuptin": {
      "command": "python3 -m server.mcp_server",
      "env": {
        "NUM_MCP_API_URL": "https://nuptin.coolify.dallico.com",
        "NUM_MCP_TOKEN": "num_mcp_VOTRE_TOKEN_ICI"
      }
    }
  }
}
ℹ Remplacez num_mcp_VOTRE_TOKEN_ICI par le jeton généré depuis le Studio. Ne commitez jamais ce fichier avec un token valide.

MCP Tool

create_optin(name, template)

Initialise un nouveau tunnel à partir d'un modèle prédéfini. Retourne immédiatement le brouillon JSON éditable sans le publier.

Paramètres

ParamètreTypeDescription
namerequisstringNom du tunnel (2 à 150 caractères). Utilisé pour générer le slug public.
templateoptionnel"app7" | "ebook1"app7 : High-Ticket 4 étapes (par défaut). ebook1 : Ebook & Lead Magnet 2 étapes.

Templates disponibles

TemplateStructureUsage idéal
app74 étapes : Capture → VSL → Candidature → RDV Cal.comCoaching, formations premium, offres high-ticket, consulting.
ebook12 étapes : Capture + Chapitre → Auteur + Amazon + WhatsAppEbooks, lead magnets, autorité d'expertise, vente Amazon.
App 7 (High-Ticket)
create_optin(name="Coaching Business Elite", template="app7")

# Ou pour un Ebook :
create_optin(name="Les 7 Leviers du Marketing Autonome", template="ebook1")

MCP Tool

update_funnel_draft(funnel_id, draft)

Remplacement complet du document JSON du tunnel — structure des étapes, formulaires, intégrations Cal.com et WhatsApp, mentions légales.

⚠ Ce tool remplace l'intégralité du draft. Lisez toujours le brouillon existant avec get_funnel() avant de modifier, puis renvoyez l'objet complet modifié. Le draft ne doit pas dépasser 120 000 caractères JSON.

Paramètres

ParamètreTypeDescription
funnel_idrequisstring (UUID)Identifiant du tunnel à modifier.
draftrequisobjectDocument JSON complet du tunnel. Doit contenir au minimum les clés copy et brand.
MCP Tool — Flux recommandé
# 1. Lire le brouillon existant
tunnel = get_funnel(funnel_id="9b156448-...")
draft = tunnel["draft"]

# 2. Modifier les champs nécessaires
draft["copy"]["title"] = "Mon nouveau titre"
draft["steps"][0]["badge"] = "ACCÈS IMMÉDIAT"

# 3. Mettre à jour avec le draft complet
update_funnel_draft(funnel_id="9b156448-...", draft=draft)
MCP Tool

publish_funnel(funnel_id)

Crée un snapshot immuable de version et active l'URL publique de production du tunnel.

! Cette action nécessite le scope funnels:publish. Toujours obtenir une confirmation utilisateur explicite avant de l'exécuter.

Paramètres

ParamètreTypeDescription
funnel_idrequisstring (UUID)Identifiant du tunnel à publier.
MCP Tool
publish_funnel(funnel_id="9b156448-...")
# → {"url": "/f/coaching-business-elite-a1b2c3", "version": 1}

Réponse

ChampTypeDescription
urlstringChemin public relatif du tunnel en production.
versionintegerNuméro de version créé (1, 2, 3…).
